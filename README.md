## 👋 About me

I build software end to end: backend services, web dashboards and mobile apps, mostly for map-heavy, data-heavy products.

- 🏢 **Full-stack engineer at [Paraboly](https://github.com/Paraboly)**, working on smart-city, transportation and GIS platforms used by public institutions in Türkiye
- 🎓 **Computer Engineering at METU** (Middle East Technical University)
- 🗺️ Into geospatial work: PostGIS, vector tiles, Leaflet and Mapbox
- 🤖 Building AI-powered products and agent workflows with **Claude Code**
- 💬 Ask me about **Spring Boot**, **NestJS**, **React / React Native** and **PostgreSQL**
